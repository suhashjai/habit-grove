Settings & data

Reminder limitation on iPhone: this offline web app can check reminder times while it is open, and may show a notification if permission is granted. iOS does not reliably schedule background notifications for a simple offline web app. For dependable scheduled reminders, use the iPhone Reminders app or a native iOS app.

Reminder permission

Add Habit Grove to your Home Screen first. Then tap below while the app is open. Notification support varies by iOS version and installation method.

Back up your data

Export a JSON backup regularly. Data stays in this browser on this iPhone; clearing Safari website data or removing the app can erase it. An export is your safety net.

Reset data

Permanently remove all habits and completion history from this app on this device.

Habit Grove is a personal offline-first tracker. It does not create an account or send your habit data to a server.
